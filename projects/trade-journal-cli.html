// Command-Line Tool

Trade JournalCLI

A lightweight terminal journal for logging trade ideas, weekly scans, and next-day plans.

View Source -> Ask About It 
$ trade-journal add
setup: Sunday scan
ticker: AAPL
plan: wait for breakout
status: logged

Problem

Trading notes need structure to be useful later.

This project organizes trade ideas and planning notes from the terminal so a trader can record the setup, plan, and follow-up without opening a larger app.

Build Notes

  • Uses a simple command-line flow for repeatable journal entries.
  • Focuses on readable prompts, organized notes, and practical output.
  • Practices Python control flow, persistence, and terminal-based UX.
