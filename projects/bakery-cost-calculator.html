// C++ Console Program

Bakery CostCalculator

A C++ program that reads product data, calculates bakery costs, and displays formatted console results.

View Source -> Ask About It 
$ ./bakery-cost
item          cost     price
croissant     1.25     3.50
muffin        0.95     2.75
highest cost: croissant

Problem

Product costs need clear calculations and readable output.

This project takes bakery product data, performs cost calculations, and prints a formatted report that makes the results easy to compare.

Build Notes

  • Reads product and recipe information from files.
  • Uses arrays, calculations, and formatted console output.
  • Practices C++ fundamentals through a realistic cost-tracking problem.

Tech Used
